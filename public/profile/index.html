This map uses the Equal Earth projection ↗ instead of the more common Mercator, which inflates countries near the poles (mostly the Global North) while shrinking those near the equator (mostly the Global South) — Greenland, for instance, appears larger than Africa on Mercator despite being 14 times smaller. Equal Earth is equal-area throughout, so every country's size on the map reflects its true relative size. Powered by d3-geo ↗, a free library for exactly this kind of thing.
