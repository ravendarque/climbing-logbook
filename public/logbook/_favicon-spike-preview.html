iOS/Android mask the PWA icon into a shape at "Add to Home Screen" time — the square PNG itself doesn't control the final shape. These previews clip the same square icon into each candidate mask so we can judge how much the mark survives the crop. Android in particular also wants extra padding (the "safe zone") since the system can crop fairly aggressively depending on the device's icon pack — the last tile shows the safe-zone margin.
