# Athlete Mode

Athlete Mode adds a Performance tab and extra detail on every climb, so the app can show you patterns in your climbing. Only you can see it.

## Turn it on

Go to **My account**, then **Settings**, and switch on **Athlete Mode**. Turn it off the same way. The details you already entered stay saved.

## What it adds

- **A Performance tab** with your [Performance Insights](/help/performance-insights/).
- **A second page on the entry form.** Press **Performance →** when you add or edit a climb.

## The extra details

- **Exertion.** How hard the climb felt, from 0 to 100 in steps of 10. Only for sends and flashes.
- **Attempts.** How many goes it took. Setting a flash makes this 1.
- **Move difficulty.** Add the hardest and easiest moves on the climb. For each one, choose the limb, hold type, movement and wall angle.
- **Pain or injury.** Add any move that hurt, the same way.

You don't have to fill everything in. Each report only uses the details it needs, and tells you which.
